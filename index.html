Panduan instalasi PWA

  1. Upload isi folder pwa_hosting_pack ke GitHub Pages / Netlify / Cloudflare Pages.
  2. Buka link HTTPS dari Safari iPhone.
  3. Tap Share → Add to Home Screen.
  4. Buka sekali saat online selama 10–20 detik agar cache offline aktif.

Catatan penggunaan

Jangan clear Safari Website Data bila ingin mempertahankan log lokal.

Log disimpan di browser iPhone menggunakan localStorage. Gunakan Export CSV secara berkala untuk backup.
