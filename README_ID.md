# HYROX Peak Training PWA

Cara pakai:
1. Upload semua isi folder `pwa_hosting_pack` ke GitHub Pages / Netlify / Cloudflare Pages.
2. Buka URL HTTPS di Safari iPhone.
3. Tap Share -> Add to Home Screen.
4. Buka sekali saat online selama 10-20 detik agar cache offline aktif.

Catatan:
- Log harian disimpan lokal di browser iPhone.
- Jangan clear Safari Website Data bila ingin log tetap ada.
- Gunakan tombol Export CSV secara berkala untuk backup.
